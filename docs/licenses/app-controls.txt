The application uses its installed @base-ui/react 1.7.0 Select and Button
primitives, with the shadcn/ui composition already present in components/ui.
AppSelect adds a native form bridge to retain the existing form handlers,
validation, FormData, reset and controlled values during migration.
No additional dashboard backend or sample accounts were imported.
