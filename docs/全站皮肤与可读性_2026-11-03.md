# 全站皮肤与可读性

默认使用清爽浅色工作台。统一正文、表格、表单、状态、提示、弹窗及 AI 面板的颜色与字号；正文约 15px，常用表格和按钮 14px，辅助说明至少 12px。预览中的海报、视频、文档纸张保留自身内容颜色。

## 皮肤

`components/workspace-theme.css` 定义共享颜色。已有业务样式通过 `--ui-*` 变量引用该配色，避免各页重新出现独立的深色界面。

清爽浅色以白、浅灰及蓝色为主。科技蓝参考 [Arwes](https://github.com/arwes/arwes) 的蓝青色、网格及角线框视觉，保留同一套字号和高对比文字。Arwes 当前公开说明其 React 组件针对 React 18，且不支持 React Server Components，因此本项目保持原有 React 19 / shadcn 交互组件，只适配其视觉语言；未导入 Arwes 运行时。来源许可保存在 `docs/licenses/arwes-MIT.txt`。

皮肤保存在当前浏览器，刷新和重新打开后继续使用；其他打开的新版标签页同步变化。默认浅色，未知或无法读取的偏好回到浅色；存储不可用时仍可在当前页面切换。

## 用户菜单

右上角头像及侧栏账户菜单共用 `WorkspaceAccountMenu`，提供选择皮肤、模型与偏好设置、切换账户、退出登录。

切换账户和退出登录均调用现有服务端退出接口，删除当前会话并清理登录 Cookie。切换账户随后显示“登录其他账号”，用户输入其他已授权账号登录。它不保存密码，也不绕过重新认证。
