# 第二阶段：剩余功能与接入流程

日期：2026-10-27。当前本地系统：http://localhost:3002 。本轮按“可本地完成的实际实现；外部条件未具备的先做配置和接入流程”实施，保留上一轮系统与数据。

## 本地新增闭环

业务模块由38类扩展至45类，新增合同与签署、订单与履约、分期回款、售后跟进、续租申请、开票申请和税务资料交接。

- 确认报价 → 合同签署资料与凭据 → 合同审核 → 一键建订单 → 确认订单 → 建履约项目。
- 按订单创建分期计划，数据库限制确认分期总额和累计应收不超过订单金额；每期分别转入现有财务应收审核，重复操作返回原单据。
- 租约可按月份和当月实际约定金额出账，同一租约同一月份去重；首末月和优惠金额由负责人按约定填写。续租申请审核后生成新租约草稿，再检查真实房源周期。
- 开票申请校验财务单据企业归属、金额和税额；税务交接关联本企业申报事项。申请确认不代表已在官方系统开票或申报。

## 接入中心

企业管理员在“接入与生产队列”管理12类接入：本地内容与媒体、DeepSeek、图片生成、视频生成、微信公众号、视频号、小红书、IoT网关、银行支付、电子发票、税务交接、专业服务。

配置字段、密钥和接入状态独立保存；支持暂时不完整的配置。密钥采用服务端AES-GCM加密，API只返回已设置的字段名。修改配置后停用流程并重置检查状态。当前本地服务会在 `data/integration-master.key` 初始化加密主密钥；备份和迁移必须保留整个data目录及该文件，不能只备份SQL后丢弃加密主密钥。线上运行需通过环境密钥设置 `PLATFORM_MASTER_KEY`。

状态含义：

| 状态 | 含义 |
|---|---|
| 未检查/待补字段 | 配置可保存，但还不能办理任务 |
| 待补凭据 | 缺少密钥，尚未进行远端测试 |
| 配置结构已核对 | 字段满足本项目要求，不代表官方平台授权或联网成功 |
| 本地条件已具备 | 本地文档/海报等可执行 |
| 自有网关回调已验证 | 已收到有效签名回调，不等于第三方官方账户已授权 |
| 流程已启用 | 允许使用本地或交接流程，不等于外部业务执行成功 |

DeepSeek岗位和内容生产已读取本企业启用连接中的加密密钥，可回退服务端原有环境配置。无密钥继续保留规则模板；真实模型队列则显示待补配置，不冒充模型生成。用户已选择暂不提供密钥，本轮未发送真实模型请求。

其他外部能力当前采用可运行的交接与回执流程：保存配置 → 选择业务版本 → 审核任务 → 下载无密钥请求包 → 由官方平台或获授权网关办理 → 签名回调或人工登记实际结果。尚未安装具体供应商直连驱动的服务，不会仅凭填写密钥就自动发布、付款、开票或生成媒体。

## 生产队列与成果

任务持久化保存业务快照、审核状态、重试次数、下次重试时间、外部任务号、成果来源和操作记录。业务版本改变后需要重建任务。失败重试有退避时间与次数上限；执行中断超过2分钟可由经理恢复。取消本地待办不表示撤回已经在外部办理的业务。

本地内容连接可在服务器直接生成并保存Markdown、可编辑DOCX、PPTX及SVG海报，成果进入业务附件。视频时间线支持镜头前后移动、素材起始秒、配乐选择与音量，保存后可渲染并上传WebM成片。当前为一条视频画面序列加一条配乐，不是完整专业多轨剪辑器；生成式图片/视频仍需选择供应商办理。

附件改为数据库分片存储，单文件8MB，保留旧附件读取能力，避免大文件放在单个D1字段。视频超过附件上限时只下载并明确说明未入库；不虚报保存成功。

## 本地文档与知识导入

在“三层知识库 → 文档入库”选择PDF、DOCX、PPTX、XLSX、TXT、Markdown、CSV或JSON。解析在浏览器本地进行，预览后将原文段落及原文件一次事务保存到本企业。大文本分段保存，原文件按SHA256去重。新记录为原始资料草稿，经过人工核对审核后才供岗位引用。

扫描图片PDF没有文本时会提示先OCR或手工整理，不把空提取或模板拼接当作OCR/知识蒸馏成功。

## 自有网关回调协议

端点：`POST /api/platform/integrations/callback/{connectionId}`。设备/服务端使用该连接配置的回调密钥，签名原始JSON正文：

```text
X-Integration-Timestamp: Unix秒级时间戳
X-Integration-Signature: hex(HMAC-SHA256(secret, timestamp + "." + rawBody))
```

时间容差5分钟。`eventId`为唯一事件编号，相同内容重放只处理一次，同一编号换内容拒绝。事件类型为 `ping`、`meter.reading`、`job.result`、`job.failed`。可运行示例为 `scripts/integration-gateway-example.mjs`；密钥读取环境变量，不使用命令参数传密钥。

```json
{"eventId":"gateway-ping-001","type":"ping"}
```

```json
{"eventId":"reading-001","type":"meter.reading","readings":[{"serial":"真实仪表编号","previous":100,"current":120,"startDate":"2026-10-01","endDate":"2026-10-31","payer":"实际缴费企业"}]}
```

仪表须属于当前连接的企业并启用。期初读数须与最近确认读数一致，读数不得倒退；合法上报进入待审核抄表，异常阈值写入提醒。此时不会自动确认收费。

```json
{"eventId":"result-001","type":"job.result","jobId":"本地任务ID","remoteId":"实际外部任务号","detail":"实际办理结果","url":"https://官方或服务商结果链接"}
```

本地服务默认只监听本机。现场网关需使用同机桥接或受信HTTPS反向代理访问回调端点。自有HMAC协议不替代微信支付APIv3的RSA验签和AES-GCM解密；支付、开票与申报回执也不会自动改写财务收付或税务状态，仍需相应责任人核对。
