# 多 Agent 执行中心

本轮在当前 React / Vinext / Cloudflare D1 项目内新增真实执行入口，不改变已有财务事务。入口为「AI与知识 → Agent 执行中心」，本地地址：http://localhost:3002/#ppt/agents 。

## 场景与能力

五类优先场景：多渠道内容生产、客户方案与报价、企业经营月报、知识库批量整理、项目风险巡检。

其余七类：招商推广、活动筹备、项目联合交付、企业供需撮合、政策匹配与材料准备、采购比价、招聘与入职准备。所有场景共用真实编排引擎，可以自动推荐场景、手动调整、编辑岗位职责、交付标准、能力、独立知识条目，并绑定已确认自定义岗位。

共20项能力：知识检索与引用、资料提取归纳、需求拆解、方案交付规划、多渠道文案、海报创意与版式说明、视频脚本、成本报价测算、进度周期评估、商机客户分析、收支现金分析、空间能耗分析、项目风险检查、企业供需匹配、活动策划、政策材料核对、采购比价、招聘培训准备、交付版本核对、统一汇总核对。

能力目录声明可以读取的数据类型及敏感性，服务器按能力裁剪模型输入。当前能力执行授权资料读取、分析、规划与文字草稿，不把海报说明、视频脚本或政策材料准备冒充已生成图片视频、已对外发布或已申报。成本、现金、采购、人事等敏感能力要求管理员或经理，敏感任务不向普通成员显示。

## 执行、人工介入与记录

1. 选择企业、业务目标、场景和可选业务项目，创建3至4个独立岗位和资料版本快照。
2. 管理员或经理查看发送范围，明确授权本执行版本向 DeepSeek 官方 API 发送任务资料、候选知识、能力范围内业务记录、人工决策及适用的财务资料。独立授权动作只记录同意，不调用模型；每次开始/恢复执行前均有范围确认。
3. LangGraph 同时调度多个独立岗位。实时读取模型公开的工作输出，不读取隐藏推理；文字先写入 D1，再通过 NDJSON 流展示。
4. 全部分支成功后才启动统一汇总。失败会阻止汇总，恢复时复用本执行版本已完成岗位，仅重试失败/中断岗位。
5. 人工可暂停、取消、编辑暂停任务中单个岗位成果，或补充新的决策。新决策推进执行代次，清空当前成果及旧授权，历史事件保留；代次与租约令牌共同拦截旧模型结果。
6. 汇总核对员检查目标、事实数字、引用版本、分歧及缺失。代码另外检查岗位引用是否合法；无知识来源、缺少引用、输出到预算上限或部分批量资料未引用会进入核对提示。
7. 管理员或经理核对并可编辑汇总，确认核对项后提交最终成果，保存确认人；已确认/已取消任务不可继续修改。

页面提供任务切换、岗位及执行版本筛选、连续文本消息、跟随新消息、知识快照查看、JSON 记录导出。每个任务的消息和成果独立。

## 知识与项目范围

- 统一读取真实 `businessRecords` 三层知识库，只有「已确认」知识可用于模型。页面演示样例不自动变成业务事实。
- 企业通用知识与所选项目知识可组合读取，其他项目与其他企业知识不会进入项目快照。企业通用任务读取通用业务记录；需处理具体项目时明确关联项目。
- 租户与项目可各自设置能力白名单、知识白名单、是否读取通用知识、并行数和输出预算。有效配置取交集与更小预算，项目配置不能扩大企业权限。
- 可复用岗位也可限制项目、知识层级及条目。单次任务再按各岗位能力和知识限制裁剪，默认按相关度选取最多6条知识。
- 共用知识页支持新增草稿、核实确认，以及 PDF/Word/PPT/Excel/TXT 等现有浏览器原文提取入库。原文件和分段资料按租户+项目去重，相同文件可在不同项目独立保存。知识原文须先核对确认，再参与模型任务。
- 知识批处理按资料分组分配给并行岗位，最多24条；各组整理事实、分类、冲突和经验，汇总岗处理跨文档核对。快照总量有上限，超额要求缩小范围，防止上下文无限膨胀。

## 调度与恢复

- 单任务并行数1至4，默认3；同企业共享4个模型名额，平台共享8个。D1 原子占位在多个请求间生效。
- 单岗位输出预算512至4000 tokens；每执行版本最多3次岗位尝试，429/502/503/504入场失败仅短暂重试一次。已开始输出的失败不会静默重放。
- 同任务使用版本检查和运行租约阻止重复执行；人工控制使用独立标记保证冲突失败不会留下虚假审计。
- 进度、分支成果、输入快照、引用、tokens、人工决策及消息都落库。模型中断时可恢复，已完成分支复用。服务重启后历史可读；执行中断后可先暂停再恢复，或待租约到期重新领取。
- 后续已改为持久化后台队列，关闭执行页面仍可运行，重新打开回放进度。当前行为与最新验收见[后台Agent与模型配置](后台Agent与模型配置_2026-10-28.md)。取消请求可阻止旧结果提交，外部供应商已开始的计算能否立即停止由供应商决定。

## 数据结构与接口

新增迁移 `0009_agent_execution.sql`，包含 `agentPolicies`、`agentRuns`、`agentTasks`、`agentEvents`、`agentSlots`；同步维护 Drizzle schema、journal 和 snapshot。

`GET /api/platform/agents` 返回有权限的任务、场景、能力、岗位、知识及策略；`id` 与 `after` 可回放消息。POST 提供创建、策略保存、独立授权、后台入队执行、暂停、决策、编辑岗位成果、取消、最终确认。所有读写使用现有登录会话和企业角色校验。
