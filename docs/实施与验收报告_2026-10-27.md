## 已贯通的关键业务

- 企业/客户 → 商机 → 需求版本确认 → 报价确认 → 一键建立项目和里程碑。
- 责任任务、范围变更、交付版本 → 验收 → 财务待审核应收 → 审核 → 分次收款 → 资金账户和账本同步。
- 实际/估算/未知成本分开记录，项目复盘审核后回知识库，知识进一步审核后供岗位接力使用。
- 采购需求审核 → 供应商报价选择 → 财务待审核应付。
- 计量点与累计读数 → 用量/单价算费 → 应收；已出账计量点不能直接变更单价。
- 空间预约、租约、内部通知/回执、人事行政、招聘培训、合作服务、活动和价值验证均可保存并追踪状态。
- CSV/XLSX字段映射、逐行预检、整批导入与导出；业务引用在服务端和数据库复合外键层校验企业归属。
- DOCX/PPTX/Markdown/SVG导出；视频镜头、时长、字幕和素材时间线可编辑、保存、预览，支持基础WebM模板渲染及SRT/JSON导出。

## 已确认的运行边界

1. 用户已授权DeepSeek官方接口的数据传输，并明确选择“暂时没有密钥，先保留规则模式”。因此本次交付默认使用明确标识的规则模板，真实模型调用未验收。之后在忽略文件 `.dev.vars` 设置 `DEEPSEEK_API_KEY`，可选 `DEEPSEEK_MODEL=deepseek-flash`，重启即可启用已实现的接口；密钥不进入浏览器或数据库。
2. 政企通知已完成内部送达和回执。微信公众号、视频号、小红书等外部渠道尚未连接，不把内部状态冒充外部发布。
3. 水电可手工录入、算费和转应收。现场IoT网关/设备协议、银行支付、电子发票及正式税务系统需要真实接口和账户，未模拟外部执行成功。
4. 图像是可编辑SVG品牌模板；视频是基础镜头时间线及静音模板渲染，不包含生成式图像/视频供应商或完整专业剪辑器。
5. 人事、行政、采购与协作按PDF画面中的轻量流程实现，不扩称全套薪资考勤、库存制造、跨企业在线签章或外部服务商履约平台。

因此，本次完成的是可使用、可持久化并贯通财务的内部业务系统；上述外部接入与专业媒体能力仍需后续条件，不能宣称PDF中所有规划能力已经全部上线。
